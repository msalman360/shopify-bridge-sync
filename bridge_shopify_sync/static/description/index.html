Setup Guide
Get Started in Minutes
Simple setup process — no technical expertise required.
1

Install the Module

Install Shopify Bridge Sync from Odoo Apps. It will appear under your Apps menu after installation.

2

Connect Your Shopify Store

Enter your Shopify store URL and API credentials. The module supports multiple stores from a single Odoo instance.

3

Run Initial Sync

Import your existing products, orders, and customers from Shopify into Odoo with a single click.

4

Enable Auto Sync

Turn on Auto Sync per record or globally. From now on, every change in Odoo is automatically reflected in your Shopify store.

🔄

Toggle Sync Per Record

Need fine-grained control? You can enable or disable automatic syncing on a per-record basis — giving you full flexibility over what gets pushed to Shopify.
