⚡ Auto Sync — Changes in Odoo? Shopify Gets Them Instantly.

Any update you make in Odoo — product price, stock, customer info — is automatically pushed to your Shopify store. No manual exports. No CSV uploads. Toggle Auto Sync per record for full control. The connector now uses Shopify's modern GraphQL API for improved performance and long-term compatibility.

🏪 Multi-Store Support

Connect and manage multiple Shopify stores from a single Odoo instance. Each store has its own independent sync settings, credentials, and tracking journal. Support for Shopify Markets & Catalogs lets you map Odoo pricelists to different markets for region-specific pricing.

🔐 Modern GraphQL API & Real-Time Webhooks

Built on Shopify's latest GraphQL API for superior speed, stability, and future compatibility. Product, order, and customer webhooks ensure your Odoo data is updated the moment anything changes in Shopify — with automatic retries on rate limits and network errors for rock-solid reliability.
