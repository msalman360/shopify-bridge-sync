Setup Guide

Get Started in 4 Simple Steps

No technical expertise required. Up and running in minutes.

1

Install Module

Install Shopify Bridge Sync from Odoo Apps. Appears under your Apps menu after installation.

2

Connect Store

Enter your Shopify store URL and API credentials. Supports multiple stores from one Odoo instance.

3

Run Initial Sync

Import all existing products, orders and customers from Shopify into Odoo in one click.

4

Enable Auto Sync

Turn on Auto Sync globally or per record — every Odoo change is automatically reflected in Shopify.
