🏪 Multi-Store Support

Connect and manage multiple Shopify stores from a single Odoo instance. Each store has its own independent sync settings, credentials, and tracking journal.

🔁 Toggle Sync Per Record

Need fine-grained control? Enable or disable automatic syncing on a per-record basis — giving you full flexibility over what gets pushed to Shopify and what stays local in Odoo. Perfect for draft products, test customers, or orders under review.

Get Started in 4 Simple Steps

No technical expertise required. Up and running in minutes.

1

Install the Module

Install Shopify Bridge Sync from Odoo Apps. It will appear under your Apps menu after installation.

2

Connect Your Store

Enter your Shopify store URL and API credentials. Supports multiple stores from a single Odoo instance.

3

Run Initial Sync

Import your existing products, orders, and customers from Shopify into Odoo with a single click.

4

Enable Auto Sync

Turn on Auto Sync per record or globally — every Odoo change is automatically reflected in Shopify.
