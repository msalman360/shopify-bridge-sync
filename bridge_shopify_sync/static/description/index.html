🏪 Multi-Store Support

Connect and manage multiple Shopify stores from a single Odoo instance. Each store has its own independent sync settings, credentials, and tracking journal.

Get Started in 4 Steps

1

Install Module

Install Shopify Bridge Sync from Odoo Apps. Appears under your Apps menu after installation.

2

Connect Store

Enter your Shopify store URL and API credentials. Supports multiple stores from a single Odoo instance.

3

Run Initial Sync

Import all existing products, orders and customers from Shopify into Odoo in one click.

4

Enable Auto Sync

Turn on Auto Sync per record or globally — every Odoo change is automatically reflected in Shopify.

🔄 Toggle Sync Per Record

Need fine-grained control? You can enable or disable automatic syncing on a per-record basis — giving you full flexibility over what gets pushed to Shopify and what stays local in Odoo.
